## Этап 2. Плагин UE: дерево одной кнопкой ⬜

- C++ Editor-плагин `UMGStudio`: создать/открыть WBP, залить дерево из текста вставки, Is Variable, Design Size,
  компиляция и отчёт об ошибках обратно в программу.
- Обновление существующего WBP по именам без потери графа и привязок; резервная копия перед записью.
- Связь программа → UE через Remote Control API (`localhost:30010`); кнопка «В UE» в окне.
- ⏳ Нужны ответы: версия движка (5.7 / 5.8), где живёт плагин, можно ли перезаписывать WBP.

## Этап 3. Обратная синхронизация ⬜

- «Забрать из UE»: плагин экспортирует дерево WBP в `<WBP>.copy.txt` (уже сейчас программа открывает copy.txt).
- Дифф «спецификация ↔ копия» в окне: какие элементы и свойства отличаются, предложение правки `.py`.

## Этап 4. То, что вставкой не задаётся ⬜

- В спецификации: `material(...)` (MI и параметры), `viewmodel(...)` / `bind(...)` (View Bindings), `parent=` (C++-база).
- Плагин создаёт MI, заводит View Bindings через MVVM Editor Subsystem, делает Reparent.
- ⏳ Нужны заголовки `UVM_*`, `ABoatHUD`, C++-баз виджетов.

## Этап 5. Анимации ⬜

- В спецификации: `anim(...)`, `track(...)` — Render Transform, Opacity, Color, параметры материала, Visibility.
- Таймлайн в превью (проигрывание, скраб); плагин создаёт `UWidgetAnimation`.
- Процедурные (пружины `FHUDMotionSettings`) — параметры в спецификации, математика как в HUD Motion Tuner.
- Анимации из Claude Design (CSS-переходы состояний в README компонентов) — основа для треков.
