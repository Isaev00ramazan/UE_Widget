# Архитектура UMG Studio

## 1. Что закрываем

| Слабое место текущего пайплайна | Чем закрывается |
|---|---|
| Вставка вручную: открыть файл → скопировать → Ctrl+V | Кнопка «В UE» в программе → плагин создаёт/обновляет WBP |
| MI, View Bindings, Custom-размер руками по таблице | Те же данные в спецификации, плагин применяет их через API редактора |
| Обратная синхронизация на дисциплине | Плагин сам пишет `<WBP>.copy.txt` при сохранении/по кнопке, программа показывает дифф |
| Не видно, как выглядит, до вставки | Превью в браузере по той же спецификации, hot reload |
| Анимации описываются словами | Анимации — часть спецификации: превью на таймлайне и `UWidgetAnimation` в WBP |

Вайбкодинг остаётся в Claude Code / Codex: агент правит `specs/*.py`, программа сразу показывает результат. Встроенный чат не нужен.

## 2. Поток данных

```
specs/<экран>.py ──(umg.py фабрики)──► дерево Python ──► IR (widget.json)
                                                            │
                     ┌──────────────────────┬───────────────┼────────────────────┐
                     ▼                      ▼               ▼                    ▼
              превью (браузер)        *.paste.txt     плагин UE: WBP      таблица «руками»
                                     (как сейчас)    + MI + MVVM + анимации   (если плагина нет)

UE: WBP ──(плагин, Ctrl+C-формат)──► <WBP>.copy.txt ──(umg_dump.py)──► дерево ──► дифф со спецификацией ──► правка .py
```

**IR** (промежуточное JSON-представление) — новое звено. Сейчас `umg.py` сразу печатает текст вставки; IR отделяет «что за дерево» от «как его вывести». Генерация `paste.txt` переезжает на IR и проверяется эталонами: для каждой существующей спецификации вывод должен совпасть байт в байт с текущим.

Черновик IR на один элемент:

```json
{
  "name": "Txt_Speed", "class": "TextBlock", "variable": true,
  "props": { "Text": "087", "Font": { "family": "BarlowCondensed", "typeface": "BoldItalic", "size": 78 },
             "ColorAndOpacity": [1, 1, 1, 1], "LetterSpacing": 0, "TextTransformPolicy": "None" },
  "slot": { "type": "CanvasPanelSlot", "anchors": [1, 1, 1, 1], "offsets": [-48, -48, 430, 120],
            "alignment": [1, 1], "autoSize": false, "zOrder": 0 },
  "children": []
}
```

Плюс на уровне экрана: `designSize`, `parentClass` (C++-база для Reparent), `materials` (MI для создания), `viewModels` и `bindings`, `animations`, `states` (наборы значений для превью).

## 3. Превью в браузере

- **Раскладка по правилам Slate, а не CSS**: свой двухпроходный layout (desired size → arrange) для Canvas (анкоры, оффсеты, alignment, auto size, z-order), Horizontal/Vertical Box (Auto/Fill, padding, выравнивание), Overlay, SizeBox, ScaleBox, Border, Grid/UniformGrid, Spacer, Retainer. Так превью совпадает с Designer, а не «похоже».
- **Текст**: px = size / 0.75, Letter Spacing в тысячных em, `TextTransformPolicy`, justification, перенос. Шрифты — те же woff2 Barlow Condensed, что в дизайн-системе.
- **Цвета**: в спецификации линейные, превью переводит в sRGB так же, как UE.
- **Материалы**: для каждого мастер-материала из `hud-kit.md` (`M_UI_Panel`, `M_UI_TextGlow`, …) — двойник на WebGL-шейдере с теми же параметрами. Если `.hlsl` простые, их можно переводить в GLSL автоматически; иначе держим ручные двойники рядом.
- **Состояния**: переключатели из `states` спецификации (обычное / LOW / CRITICAL / EMPTY и т. п.), Collapsed честно убирает элемент из раскладки.
- **Анимации**: таймлайн с проигрыванием и скрабом, кривые те же, что уйдут в UE.
- **Оверлеи**: рамка safe-margin 48px, сетка 1920×1080, подсветка элементов ✎ (Is Variable), сравнение с эталонной картинкой из Claude Design (наложение с прозрачностью).

## 4. Анимации

Два вида, оба в спецификации:

1. **Таймлайновые** (`UWidgetAnimation`) — появление, мигание LOW, пульс, слайды. Треки: Render Transform (translation/scale/angle/shear), Render Opacity, Color and Opacity, параметр материала, Visibility. Ключи + интерполяция (linear/cubic/constant) и касательные.
   ```python
   anim("Anim_LowPulse", length=0.8, loop=True, tracks=[
       track("Bar_Fill", "RenderOpacity", keys=[(0, 1.0), (0.4, 0.45, "cubic"), (0.8, 1.0)]),
       track("Txt_Low", "RenderTransform.Scale", keys=[(0, (1, 1)), (0.4, (1.08, 1.08)), (0.8, (1, 1))]),
   ])
   ```
2. **Процедурные** (пружины, как `FHUDMotionSettings`) — код в C++-базе. Спецификация хранит только параметры, превью исполняет ту же математику на JS (как уже сделано в HUD Motion Tuner), плагин пишет значения в Details.

## 5. Плагин UE (`UMGStudio`)

Editor-модуль C++ с BlueprintCallable-библиотекой, чтобы его можно было звать и из Python, и снаружи.

| Операция | Как | Риск |
|---|---|---|
| Создать/открыть WBP | `AssetTools` + `UWidgetBlueprintFactory`, родитель из `parentClass` | низкий |
| Залить дерево | Вариант А: тот же текст вставки через импорт UMG-буфера (`FWidgetBlueprintEditorUtils`, проверить экспорт символов). Вариант Б: собрать `WidgetTree` вручную, свойства через `FProperty::ImportText` из IR. Начинаем с А — переиспользует проверенный формат | средний |
| Обновить существующий WBP | Сопоставление по имени: элементы с тем же именем обновляются, а не пересоздаются — привязки и графы не ломаются | средний |
| Is Variable, Design Size | `bIsVariable` у виджета, `DesignTimeSize`/`DesignSizeMode` у CDO | низкий |
| MI | `UMaterialInstanceConstant` + параметры (как в `ue_setup_hud.py`) | низкий |
| View Bindings | `UMVVMEditorSubsystem` (AddViewModel / AddBinding / пути) | средний, проверить на версии движка проекта |
| Анимации | `UWidgetAnimation` + `UMovieScene` possessable на виджет + треки | высокий — делаем последним |
| Экспорт `copy.txt` | тот же код, что Ctrl+C в Designer, по кнопке и на сохранение ассета | низкий |
| Компиляция и проверка | `FKismetEditorUtilities::CompileBlueprint`, отчёт об ошибках и «не найденных BindWidget» обратно в программу | низкий |

**Связь программа ↔ UE**: встроенный плагин Remote Control API (HTTP, `localhost:30010`, вызов функций библиотеки) — без своего сетевого кода. Запасной путь: Python Remote Execution. Если редактор закрыт — программа складывает задание в папку, плагин подхватывает при старте.

**Безопасность ассетов**: перед обновлением плагин делает копию `.uasset` (или проверяет, что файл чист в VCS), всё в одной транзакции редактора — Ctrl+Z работает.

## 6. Программа

Десктопное приложение для Windows: собственное окно, иконка, ярлык, без вкладки браузера.

- Внутри окна — веб-интерфейс на системном WebView2 (это тот же Chromium, что в Edge/Chrome), обёртка `pywebview`. Превью обязано быть веб-движком (шрифты, WebGL-материалы, HTML из Claude Design), поэтому окно и браузер рисуют одинаково.
- Python-бэкенд в том же процессе: следит за `specs/`, пересобирает IR, связывается с UE; команды «Сгенерировать paste», «В UE», «Забрать из UE», «Дифф».
- Сборка в один `UMGStudio.exe` через PyInstaller. Для разработки тот же интерфейс открывается и в обычном браузере — так его можно проверять автоматически (Playwright) без Windows.

| 0. Перенос | `umg.py`, `umg_dump.py`, спецификации и эталоны в репозитории; IR; тесты «спецификация → paste.txt» совпадают с текущими | файлы скиллов |
| 1. Превью | браузерное превью `race_results.py` один в один с Designer (проверка по скриншоту) | шрифты, hud-kit, мастер-материалы |
| 2. Плагин: дерево | кнопка «В UE» создаёт/обновляет WBP, Is Variable, Design Size; экспорт `copy.txt`; дифф | версия движка, тестовый проект |
| 3. Плагин: MI, MVVM, Reparent | таблица «руками» больше не нужна | список VM, мастер-материалы |

| 5. Удобства | наложение эталона из Claude Design, растр иконок из SVG по кнопке | — |
