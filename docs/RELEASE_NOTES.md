## UMG Studio {version}

Первая сборка для скачивания: **`UMGStudio-{version}-win64.zip`** — распаковать и запустить `UMGStudio.exe`
(Python не нужен). Плагин редактора отдельно — **`UMGStudio-Plugin-{version}-UE5.8.zip`** (он же внутри основного архива, `ue\`).

### Новое в v0.4.0 — правка свойств и ИИ в программе
- **Свойства правятся прямо в панели справа.** У каждого значения есть своё поле:
  - числа, флажки и списки (выравнивание, Justification, Size Auto/Fill…);
  - цвет: палитра, HEX и альфа (в файл пишется линейный, как в UE);
  - текст;
  - шрифт: Size и px дизайна рядом.
  
  Флажки Is Variable и Collapsed. «{}» — строка как в UE, «×» — убрать свойство, «+ свойство» — из шаблонов класса
  (Text, Font, Shadow, Padding, Size Fill, Layout Canvas…).
- **Изменение сразу видно в превью; «Сохранить» (Ctrl+S) записывает его в спецификацию `.py`.**
  - Спецификации, собранные из UE (`W(...)`): меняется одна строка нужного словаря, остальной файл не трогается.
  - Спецификации на фабриках (`text()`, `image()`, слоты `bs()`…): правка ложится строкой `tweak(...)` под
    импортом umg. Кнопка «Встроить правки в код» в чате ИИ переносит её в вызовы.
- **✦ ИИ — Claude Code на твоём компьютере**, по подписке, без ключа API. Пишешь, что поменять, Claude правит
  `.py`, превью обновляется само.
  - Видно, какие файлы он читает и правит.
  - Он знает открытый экран, выбранный элемент с его свойствами и последнюю ошибку спецификации, а также правила
    из скилла umg-widgets (его программа кладёт в рабочую папку).
  - Диалог продолжается, пока не нажмёшь «Новый».
  - Правит только файлы в рабочей папке, команды не запускает.
  
  Нужен установленный Claude Code (`claude`), в котором ты один раз вошёл в аккаунт. Путь и модель можно задать в «⚙ Проект».
- **↶ Отменить** вверху возвращает файлы как до последней правки, свойств или ИИ.
- **Значок у `UMGStudio.exe`.** Кадры иконки были в PNG, и Проводник показывал стандартный значок. Теперь маленькие
  кадры в BMP, а сборка сверяет значок exe с логотипом.

### Исправлено и новое в v0.3.1
- **Плагин выгружал только корень виджета** (в UE 5.8 детей при выгрузке добавляет сама кнопка Ctrl+C) — в
  программе было «?» и 0×0. Теперь выгружается всё дерево. **Переустанови плагин** и пересобери проект.
- Если дерево всё же пришло неполным, программа не создаёт из него `.py`, а пишет, что обновить.
- **Текстуры в превью — прямо из открытого UE** (`T_Mage` и любые другие), без выгрузки PNG.
- **«Пересоздать .py из UE»** — для спецификаций, собранных из UE: забирает дерево заново, старый файл → `.py.bak`.
  Твои `wb_box.py` / `wb_image.py` из прошлой версии пересоздай этой кнопкой после обновления плагина.

### Новое в v0.3.0 — работа с любым проектом
- **⚙ Проект** (кнопка вверху): папка проекта UE, рабочая папка спецификаций, `.hlsl`, `ue_setup_hud.py`, выгрузка MI,
  текстуры, дизайн-система, а также **пути в Content**: папка виджетов, шрифт, материалы, текстуры. Хранится в
  `umgstudio.json` рядом с программой. Пустые поля считаются от папки проекта.
- **Проект подхватывается сам**: открыт редактор с плагином, а проект в настройках не задан → программа берёт его,
  файлы кладёт в `<Проект>/UMGStudio`.
- **Слева «В проекте UE»** — все Widget Blueprint проекта (поиск). Клик по виджету: дерево забирается из UE,
  программа сама пишет спецификацию `.py` (+ `copy.txt`) и открывает её. Дальше правишь `.py` → «В UE ▶».
  ● у виджета — для него уже есть спецификация.
- **Забрать по пути**: поле под списком — `/Game/…/WBP_Имя` (Content Browser → Copy Reference). Работает и со старым плагином.
- **«Сделать .py»** у любого `copy.txt` / `paste.txt`. Спецификация даёт то же дерево, что в UE (проверено тестом на всех примерах).
- **Вложенные виджеты** (WBP внутри WBP), которых нет на диске, превью берёт прямо из открытого UE.
- Плагин обновлён (список виджетов, папка проекта, родитель и размер превью при выгрузке) — переустанови:
  `ue\install_plugin.bat "<папка проекта>"` и пересобери проект.

### Исправлено в v0.2.3
- v0.2.2 запускалась и сразу закрывалась: окну передавался значок PNG, а WinForms принимает только .ico —
  исключение .NET молча завершало процесс. Сборка теперь открывает настоящее окно на Windows перед релизом.
- Если окно всё же не загрузит интерфейс: теперь окно проверяет, что интерфейс действительно загрузился;
  если за 20 секунд нет — закрывает его и открывает программу в Edge отдельным окном. Каждый шаг запуска и ошибки
  интерфейса пишутся в `%LOCALAPPDATA%\UMGStudio\log.txt`. Сборка перед релизом открывает настоящее окно на Windows.

### Новое в v0.2.2
- Значок программы: у `UMGStudio.exe`, у окна и на вкладке.

### Исправлено в v0.2.1
- Программа падала при запуске из скачанного архива (`Failed to resolve Python.Runtime.Loader.Initialize`): Windows
  помечает файлы из интернета, и .NET не грузил DLL окна. Теперь пометка снимается при запуске, а если окно pywebview
  всё равно не открылось — программа открывается в Edge в режиме приложения (отдельное окно), в крайнем случае в браузере.
  Причина сбоя пишется в `%LOCALAPPDATA%\UMGStudio\log.txt`. Режим окна можно задать в `umgstudio.json`: `"window": "edge"`.

### Что умеет
- **Превью как в Designer**: раскладка по правилам Slate (Canvas, Box Auto/Fill, Overlay, SizeBox, Border, Grid, ScaleBox, Retainer, вложенные WBP), шрифт F_HUD из дизайн-системы + кириллица Fira, Size UE × 4/3 = px.
- **Материалы — ваш HLSL**: `.hlsl` мастеров переводится в GLSL и считается на видеокарте тем же кодом, что в UE.
- **Живое обновление**: сохранили спецификацию — превью обновилось; ошибка — в окне с трассировкой.
- **Сверка с Claude Design**: макет компонента поверх превью (прозрачность / разница / только макет) или рядом с README.
- **Hierarchy и свойства**: ✎ Is Variable, шрифт в px, цвета HEX + линейные, переключение Collapsed, состояния `umg.state()`.
- **«Скопировать»** — текст вставки в буфер обмена (в Designer: Ctrl+V).
- **«В UE ▶» / «Забрать из UE» / «Сравнить с UE»** — через плагин UMG Studio Bridge: WBP создаётся/обновляется, компилируется и сохраняется (с резервной копией); дерево из UE сравнивается со спецификацией.
- **Предупреждения вёрстки**: содержимое не влезает в панель, Size в MI ≠ размер Image, нет вложенного виджета.
