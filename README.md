# UMG Studio

Отдельная программа для вайбкодинга виджетов UMG и их анимаций с импортом в Unreal Engine одной кнопкой.

Вид, раскладка и анимации описываются в спецификации (`.py`-дерево на фабриках `umg.py`). Спецификация — единственный источник правды. Из неё получаются три вещи:

1. **Превью в браузере** — обновляется при сохранении файла, с переключением состояний и проигрыванием анимаций.
2. **Текст вставки** (`*.paste.txt`) — как сейчас, запасной путь без плагина.
3. **Ассет в UE** — редакторный плагин сам создаёт или обновляет WBP: дерево, слоты, Is Variable, размер превью, MI, View Bindings, анимации.

Обратно: плагин по кнопке экспортирует дерево WBP в `<WBP>.copy.txt`, программа показывает разницу со спецификацией и переносит ручные правки в `.py`.

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Что нужно от автора проекта для старта: [docs/NEEDED.md](docs/NEEDED.md).

## Структура (планируемая)

```
studio/            Python: ядро спецификации (umg.py, IR), CLI, локальный сервер, наблюдение за файлами
studio/web/        превью в браузере: раскладка по правилам Slate, шрифты, материалы, таймлайн анимаций
ue/UMGStudio/      плагин UE (Editor-модуль C++ + Python): импорт/экспорт WBP, MI, MVVM, анимации
specs/             спецификации экранов (*.py) и сгенерированные *.paste.txt
tests/golden/      эталоны: спецификация → paste.txt, copy.txt → дерево
```
