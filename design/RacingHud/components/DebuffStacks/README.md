Бейдж дебафа со стаками (Slow, до 3 стаков). Механика: 1-й стак −20% на 3 с, 2-й −30%, 3-й −40%; каждое попадание после первого +1.5 с, остаток не выше 6 с; по истечении снимается целиком.

Число стаков показываем тремя пипсами: пустые слоты видны всегда, поэтому предел 3 читается без подписи. Ширина бейджа фиксированная — 200 px при любом числе стаков, чтобы соседние бейджи не прыгали.

## Состояния

| Состояние | Класс | Что меняется |
| --- | --- | --- |
| 1 / 2 стака | `debuff--stack` | горят 1 / 2 пипса |
| 3 стака, максимум | `debuff--max` | обводка inset 1.5px rgba(192,140,255,.85), пипсы со свечением 0 0 8px rgba(192,140,255,.8) |
| Попадание, +стак | `debuff--hit` + `i.new` | 220 мс ease-out: заливка rgba(192,140,255,.28) → 0, обводка 1.5px #C08CFF + внутреннее свечение 14px; новый пипс #FFF со свечением 10px → #C08CFF; процент и время белые → свои цвета; чип «+1.5s» поднимается на 8 px и гаснет за 600 мс |
| Попадание на 3 стаках | `debuff--hit-time` | пипсы не меняются, пульсирует только время (белое со свечением 10px), чип «+1.5s» |
| Потолок 6 с | `debuff--cap` | время 6.0s белое, полоска полная и белая `ink` со свечением 8px на 400 мс; чип показывает реально добавленное «+0.7s · MAX» (белый текст, обводка rgba(243,246,242,.55)); если уже было 6.0 — чип «MAX» |
| Последняя секунда (≤ 1.0 с) | `debuff--ending` | время #C08CFF, бейдж мигает 4 Гц: 125 мс 100% / 125 мс 45%; при reduced motion без мигания |
| Снятие | `debuff--collapse` | ширина 200 → 0 за 150 мс ease-in, прозрачность → 0, все стаки сразу; соседи сдвигаются |
