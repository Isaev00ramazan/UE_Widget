Круги, топ-5 и радар — правый верх, зона гонки. Радар Ø232 (токен `radar-size`); панель лидерборда доходит до его центра, вырезана по окружности радиусом R+5 (R — половина радара) и уходит под обод (без зазора), поэтому выглядит вставленной в радар. Отрывов по времени нет — только место и имя. В заголовке `LAP 2/3`, справа полоски кругов (текущий заполняется по ходу круга) и под ними сколько осталось; на последнем — `FINAL LAP` оранжевым. Если игрок не в топ-5, его строка с настоящим местом заменяет пятую. Строка игрока — `player`.
