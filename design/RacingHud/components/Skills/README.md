Два навыка в одной панели `ABILITIES` боевого дока: главный (Dive, 96px) и второй (Sonar, 64px). Иконки в стиле «иллюстрация» заполняют весь диск. Под каждым — название и клавиша, круги выровнены по низу. Готов: золотое кольцо со свечением, название белое. Перезарядка: кольцо заполняется по часовой, картинка обесцвечена и затемнена, в центре секунды. Активен: бирюзовое кольцо и свечение по краю диска, в названии остаток (`DIVE 78%`). Недоступен: пустое кольцо, картинка серая.
